# Договорка — AI-аудитор договоров (Готовый SaaS-проект)

Полностью готовый к запуску и монетизации SaaS-сервис для анализа юридических договоров с помощью искусственного интеллекта. Проект написан на современном стеке и готов к передаче новому владельцу.

## 🚀 Что входит в проект:
* **Продающий лендинг:** Главная страница с описанием, тарифами и призывом к действию.
* **Авторизация:** Полноценная система регистрации и входа на базе Supabase.
* **Личный кабинет (Дашборд):** Интерфейс для загрузки файлов (PDF, DOCX, TXT) и вывода результатов.
* **ИИ-анализ:** Готовая интеграция с нейросетью GigaChat для поиска скрытых рисков и генерации рекомендаций.
* **Страница оплаты (Checkout):** Красивый интерфейс кассы с валидацией карт по алгоритму Луна (готова к подключению реального эквайринга).
* **Служба поддержки:** Форма обратной связи с отправкой уведомлений напрямую в Telegram.
* **Юридическая защита:** Готовые страницы с Пользовательским соглашением и Политикой конфиденциальности (составлены с учетом требований 152-ФЗ).
* **Плавающая кнопка поддержки:** Удобный виджет чата на всех страницах сайта.

## 🛠️ Технологический стек:
* **Фреймворк:** Next.js (App Router)
* **Стили:** Tailwind CSS
* **База данных и Auth:** Supabase
* **Нейросеть:** GigaChat SDK
* **Язык:** TypeScript
